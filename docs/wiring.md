# 重新建立接线与单电机调试方案

不依赖旧程序或旧操作资料。当前采用电脑作为上位机，使用现有 USB2CAN 逐台测试；这是新方案，不代表已确认历史接法。ESP32-S3 独立控制放在单电机测试通过后。

## 已知与待核实

- 用户确认：两台 USB2CAN、两块电源／CAN 转接板；H3510 引出接口为 8 pin 和 3 pin。
- 用户描述电池为 22V 锂电池。标称电压、串数、满电电压和当前实测值未核实，不能据此批准给电机供电。
- H3510 官方 V1.0 手册注明供电 24–30V。若当前实测只有 22V，则低于此手册范围；先解决供电匹配，再判断通信或机械故障。
- 暂未从照片中确认独立的 ESP32 用 CAN 收发器模块；不将电源／CAN 转接板视为收发器。

## H3510 怎样接到 USB2CAN

官方手册注明：8 pin 是电源＋CAN，3 pin 是调试串口。配套转换板规格为 **SH1.0 3pin＋8pin 转 XT30＋GH1.25**。需确认现有板是否支持这一规格；只有组合插头的转接板不能直接插入电机的 8 pin。

```text
电脑 USB ─ USB2CAN ─ CANH/CANL ─ H3510 适配转接板 ─ 8 pin ─ H3510
匹配规格的电源 ─ 保护与停机回路 ─ 转接板电源输入 ─────┘
```

上图是功能连接关系，不是连接器针脚顺序。电源正负极、H/L、地参考与隔离方式均须按实际板卡说明核对；USB 不能代替电机动力电源。

3 pin 是另一路串口调参接口，不直接接 CANH/CANL。需串口调参时，通过匹配转换板连接支持该串口的调试工具；USB2CAN 是否另带兼容 UART 接口，须核对其版本和端口标记。仅走 CAN 控制时，无须为了凑接口把 3 pin 也接上。

因此可能缺的是 H3510 专用转换板和线束，不一定缺第三个 USB2CAN。一个工具可在断电后换接不同电机，逐台测试。

## CAN 收发器与 USB2CAN 的区别

USB2CAN 是电脑到 CAN 的完整接口工具，CAN 侧具备物理层收发能力；无需在其 CAN 输出后再串一个收发器。电源／CAN 转接板只负责连接器分接。

ESP32-S3 内置 TWAI 控制器，但没有 CAN 收发器。以后使用 ESP32 时，需要带 TXD、RXD、CANH、CANL 等接口、逻辑电平兼容 3.3V 的收发器模块，例如基于 SN65HVD230 的模块；具体模块供电、使能及终端电阻要核对实物。不能直接把 ESP32 GPIO 接到 CANH/CANL，也不默认能借用 USB2CAN 内部的芯片。

ESP32-S3 的 GPIO4/TX、GPIO5/RX 仅作为候选分配，开发板型号及占用未核实前，不作为可照接的针脚表。ESP32-S3 内置 TWAI 不支持 CAN FD，后续应确认所有电机使用兼容的经典 CAN 配置。

## 今天的连接和验证顺序

1. 拍电池标签并测当前电压，确认电源与所测电机要求匹配；记录分电板每个已接支路的去向，空口不自动视为小电机专用口。
2. 将两个 USB2CAN 标为 A、B；先只连接 A 到电脑，确认设备名称、硬件 ID、端口、板卡版本及匹配的达妙调试软件。天线组件暂不参与单电机测试。
3. 先选线束已核实的一台电机，按对应手册接电源和通信，核对终端电阻配置。单条总线两端配置终端，不将每个设备的终端全部打开。
4. 首先读设备信息、ID、模式、波特率及故障反馈并保存；不要先恢复出厂或刷固件。不能通信时按供电、软件端口、线序、速率和终端逐项检查。
5. 确认固定、防护及停机条件后，再进行受控启停测试；刀片电机优先在不带切削负载的条件下验证。保存反馈和结果。
6. 断电后换下一台，分别建立三台电机记录。逐台通过后，再设计共用 CAN 总线及 ESP32 控制，避免电脑与 ESP32 同时发动作指令。

电脑不需要同时插四个 USB 来完成逐台测试。天线组件的原用途仍未知；多 USB 的存在只能支持“可能曾用于电脑调试”的猜测，不能证明原控制架构。
