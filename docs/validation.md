## 覆盖的行为

- 上电停止、板级未核对时拒绝使能、真机拒绝模拟故障指令。
- 单操作端所有权、观察端不能运动但能全部停止、控制端断开停机。
- 500 ms 心跳过期、重复/乱序/过期命令、错误字段类型、重复 JSON 键、过长与过深输入处理。
- 左右差速方向、限幅、加减速、单机/整车模式互斥、刀片独立解锁与禁止反转。
- 运行电机反馈丢失、驱动故障、CAN 故障；故障解除和重启后不恢复旧目标。
- H3510 离线时仍可测试行走电机；离线状态不伪装成零速或已失能。
- 配置模型、ID 冲突、方向、单位范围、反馈超时；持久化失败恢复原配置。
- 两型号的速度编码、特殊指令、反馈解码、非法帧不更新反馈时间。
- 浏览器实际鼠标拖出按钮后松开、手机触摸释放、键盘单机测试、失焦停机、重连、配置编辑和带模拟标记的 CSV 导出。
- 桌面与手机页面无横向溢出；浏览器测试未发现页面脚本错误。

电机测试向量的依据及“厂家示例/格式推导/合成数据”的区别见 [motor-protocol-evidence.md](motor-protocol-evidence.md)。
