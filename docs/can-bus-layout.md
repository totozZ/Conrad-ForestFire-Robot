# 三台电机如何共用 CAN 总线

## 结论

**ESP32-S3 真机控制不需要三个 USB2CAN，也不需要三个 USB 接电脑。**
保留每台电机已有的电源/CAN 转接板，把它们的 CAN 口接入同一条总线；ESP32-S3 经一块外置 CAN 收发器接这条总线。
电脑和手机用 Wi-Fi 网页操作，ESP32 的 USB 主要用于烧录、主控调试和开发阶段供电。

即便先继续用电脑调试，也可以使用 **一个 USB2CAN → 一条总线 → 三台不同 ID 的电机**。
官方软件是否能同时绘制三台曲线取决于它的功能，但物理连接不需要一电机一 USB。

## 你目前的接法如何改

现在每台分别这样接：

```text
电机 ── 电源/CAN转接板 ── CAN口 ── USB2CAN ── 电脑
                  └── 电源口 ── 动力电源
```

改成：**电源部分保留，CAN 口从各自的 USB2CAN 拔下，改接共用总线。** H3510 仍须等待它的专用转接板，不用其他连接器强行代替。

```text
电脑 / 手机网页
       │ Wi-Fi（连接机器人热点）
   ESP32-S3
       │ GPIO TX → TXD；RXD → GPIO RX；逻辑供电与地按模块说明
   外置 CAN 收发器
       │ CANH / CANL
       ╞══ 双绞线主干 ══ 左轮分接点 ══ 右轮分接点 ══ 刀片末端
                          │ 短支线       │ 短支线       │
                       左6215转接板   右6215转接板   3510专用转接板
                          │             │             │
                       左6215电机     右6215电机     3510电机
```

这是一条总线上多个节点，**不是电气串联**。三个 H 都接总线 H，三个 L 都接总线 L；H 和 L 是两根不同导线，不能短接。
设备顺序不代表地址顺序，可随车架走线调整；布线采用主干依次经过节点、支线短的形式，不拉三条很长的线从一个中心点向外放射。

## 每个转接板只有一个 CAN 插口怎么办

用匹配实际接口的 **CAN 直通分接线、T 型分接线或被动分接端子**：

| 分接位置 | 电气连接 |
| --- | --- |
| H 端子 | 上一段主干 H、下一段主干 H、该电机转接板 H 接在一起 |
| L 端子 | 上一段主干 L、下一段主干 L、该电机转接板 L 接在一起 |
| 电源口 | 独立接动力分支，不通过这两根 CAN 信号线供电 |

中间节点需要“主干进、主干出、本机短支线”三个方向。末端节点只需要进线和本机连接。
不要求电机本身提供第二个 CAN 插口，也不需要再加一块 USB2CAN 来转发。
插头间距、针数、线序以已有板卡为准；同为 GH1.25 不保证针序相同。先追踪板上 H/L 标记，再制作接头。

## 终端电阻与地参考

主干**物理两端**各放一个 120 Ω 终端电阻，接在 H 与 L 之间。中间节点不重复增加终端。
上图可将收发器端和刀片末端作为两端，但需先检查电机、USB2CAN、收发器或转接板上是否已有终端，不能直接再加两只。[TI 官方终端说明](https://www.ti.com/tool/TIDA-01238)

对于确认采用“两只 120 Ω 并联”的完整总线，可在全部断电、排除其他电路影响后测 H–L 电阻，约 60 Ω 仅用于核对终端数量，不能证明 H/L 极性、CAN 参数或运行状态正确。
线缆两端都应持续有终端；拆下末端电机后，如果同时拆掉终端，需要重新确认总线末端。

非隔离方案按电机和模块说明建立公共地参考：ESP32 GND、收发器 GND 和 CAN 节点的参考地必须兼容；电机的大电流回路走动力线，不能经过主控细地线。
若选隔离式模块，按其总线侧地、隔离供电和逻辑侧说明接线，不自行把隔离两侧短接。
两针 CAN 口只有 H/L，不意味着整套系统不需要地参考。[TI CAN 物理层说明](https://www.ti.com/lit/an/slla270/slla270.pdf)

## 电源依然按分支并联

```text
匹配的动力电源 → 保护 / 实体动力切断 → 分电
                                      ├── 左6215转接板电源口
                                      ├── 右6215转接板电源口
                                      └── 3510转接板电源口

经核对的逻辑电源 / 调试USB → ESP32-S3及收发器所需供电
```

这张图只在共同动力电压满足三台实际电机时成立。H3510 当前参考手册为 24–30V，现有“22V 锂电池”的串数、满电/工作电压仍需核实；不能直接认定一块电池满足全部工况。
动力正负极不串联，USB 不给电机提供动力；已有 19V DC-DC 也不能直接接 ESP32 供电口。

## 接入前配置与需要准备的东西

1. 用现有 USB2CAN **逐台连接**，读取并记录 CAN ID、Master ID、模式和波特率；不要先把可能同为出厂 ID 的三台并在一起。
2. 规划不重复的 ID。例如 CAN ID 1/2/3、反馈 ID 17/18/19 **只是可选规划示例**，不是当前实物参数。实际修改后重新读回确认，再填写网页配置。
3. 三台统一到与实物匹配的经典 CAN 速率；本版不使用 CAN FD。先保留低速且有依据的机构测试上限。
4. 接上共用总线与收发器，确认终端和地参考，再逐台在 ESP32 页面读取反馈、低速使能测试。
5. 从电脑控制切到 ESP32 时，关闭官方工具的动作发送；不要让两个控制器同时发速度命令。若留 USB2CAN 观察，需确认其接入方式、终端和监听能力。

| 物料 | 数量 / 用途 |
| --- | --- |
| ESP32-S3 | 已有，完整开发板型号仍待核实 |
| 兼容 ESP32 逻辑电平的 CAN 收发器模块 | 1 块，选定后再锁定 VCC、TXD、RXD、EN 与引脚接法 |
| 电机电源/CAN 转接板 | 每台对应一套；两台 6215 沿用，3510 等专用板 |
| CAN 双绞线与匹配分接接头 | 一条主干，两个中间节点的短分接，末端接头；长度按车架实际路径 |
| 终端电阻 | 全总线有效两处，先核对板载终端再决定补购数量 |
| 合适的动力保护、切断与逻辑稳压 | 根据实际电源、负载和主控核对 |
| USB2CAN | 已有设备用于调参和诊断；真机不要求每台电机固定配一块 |

天线组件由用户判断疑似蓝牙模块，尚未核实芯片与协议。当前网页链路用 ESP32 自带 Wi-Fi，不依赖这组旧模块，也不能把它直接当成 CAN 收发器。
